For each finding, provide file locations, evidence, consequence, smallest proposed change, confidence, and verification needed. Report findings without editing code.

Audit the whole codebase for:
1. Multiple sources of truth: the same state, config, constants, types or business rules defined or derived in more than one place
2. Code duplication: copy-pasted logic, near-identical functions or components
3. Simplification: dead code, needless layers, over-generic code, hand-rolled helpers that duplicate the standard library or a framework

For each finding, give the file:line references, why it's a problem, the suggested fix and a rough effort. Rank them by impact. Don't change any code yet.
